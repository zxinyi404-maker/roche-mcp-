# Roche 智能联网助手

让 AI 在**正常聊天窗口**自动判断何时需要联网，无需打开单独页面。

## 核心特性

✅ **完全自动** — AI 自己判断何时需要搜索或浏览网页，无需你手动触发  
✅ **零感知使用** — 在正常聊天窗口使用，不需要打开插件页面  
✅ **智能判断** — 当你提到最新信息、具体人物/事件时，AI 会主动联网  
✅ **保持人设** — 联网后仍然以角色身份回复，融入对话风格  

## 工作原理

1. 插件在后台拦截 `roche.ai.chat` 调用
2. 给 AI 注入工具使用说明（搜索、打开网页）
3. AI 判断需要联网时，自动输出工具调用
4. 插件执行工具，把结果喂回 AI
5. AI 基于结果给出最终答案

整个过程对用户透明，就像 AI 天然会联网一样。

## 安装步骤

### 1. 上传到 GitHub

1. 在 GitHub 创建新仓库（比如 `roche-auto-web`）
2. 把 `manifest.json` 和 `plugin.js` 上传
3. 修改 `manifest.json` 里的 `entry` 字段：
   ```json
   "entry": "https://raw.githubusercontent.com/你的用户名/roche-auto-web/main/plugin.js"
   ```

### 2. 在 Roche 里安装

1. 打开 Roche → 插件 → 安装
2. 填入 `manifest.json` 的 Raw 链接：
   ```
   https://raw.githubusercontent.com/你的用户名/roche-auto-web/main/manifest.json
   ```
3. 确认权限后安装

### 3. 配置代理地址

安装后会自动弹出配置窗口，填入你的 CORS 代理地址：

```
https://jbcjkfcfnsak-xinchajian.hf.space/proxy
```

（你已经有这个代理了，直接填就行）

如果没弹出，可以：
- 打开 Roche 桌面的"联网设置" App
- 填入代理地址并保存

## 使用方法

**安装后不需要任何操作！**

直接在聊天窗口正常对话，AI 会自动判断何时联网。

### 示例对话

**你：** 我最近刷到一个博主叫李子柒  
**AI：** *（自动搜索"李子柒"）* 根据最新信息，李子柒是...

**你：** 帮我看看今天北京天气  
**AI：** *（自动搜索"北京天气 今天"）* 今天北京...

**你：** https://example.com 这个网站讲了什么  
**AI：** *（自动打开网页读取）* 这个网站主要讲...

## 注意事项

⚠️ **AI 联网会消耗更多 tokens** — 每次工具调用都是额外的 AI 请求  
⚠️ **需要配置 CORS 代理** — 用于绕过浏览器跨域限制  
⚠️ **DuckDuckGo 可能反爬** — 搜索失败时检查代理是否正常  

## 与 browser-mcp 的区别

| 特性 | browser-mcp | auto-web (本插件) |
|------|-------------|-------------------|
| 使用方式 | 打开单独的插件页面 | 在聊天窗口自动调用 |
| 触发方式 | 手动发送消息 | AI 自动判断 |
| 记忆互通 | 需要手动挂载会话 | 使用 Roche 原生记忆 |
| 界面 | 独立聊天界面 | 无界面，后台运行 |

## 技术细节

- **无侵入** — 只拦截 `roche.ai.chat`，不修改 Roche 代码
- **循环执行** — 最多 5 步工具调用，防止无限循环
- **错误处理** — 工具失败时 AI 会基于已有信息回答
- **代理通信** — 所有外部请求通过你的 CORS 代理转发

## 故障排查

### AI 不联网
- 检查插件是否启用（打开"联网设置"查看状态）
- 检查代理地址是否正确
- 试试直接问"帮我搜索xxx"

### 工具调用失败
- 检查代理服务器是否正常运行
- 检查代理地址末尾是否是 `/proxy`
- 查看浏览器控制台的错误信息

### AI 多次调用工具但没结果
- 正常现象，AI 可能需要多次搜索/浏览
- 如果超过 5 次会强制输出答案
